case study , akaunsaya.my

Personal expense tracker, built to feel like a product

Built as a full PWA rather than a basic form-and-list app , the kind of attention to detail a client project gets.

Problem
Needed a way to track daily expenses that actually felt fast enough to use every day, on mobile.
Approach
PWA architecture so it installs like a native app, with offline-friendly UI and real-time sync.
Stack
Next.js, React, Supabase, Tailwind CSS, deployed on Vercel.
Outcome
Installable, mobile-first app with authenticated real-time data , live and in daily use.
